# 接口测试台

一个本地运行的可视化接口测试工具，用来替代逐个写 Python 脚本测试内网接口的方式。

## 为什么是本地运行，不是网页 Artifact

你的接口地址是内网 IP（`172.16.x.x`），只有在你自己电脑所在的网络里才能访问。
所以这个工具是一个**在你电脑本地跑的小型 Web 服务**：网页界面在浏览器里，
但真正发请求的是本地的 Python 后端（跟你原来的脚本一样用 `requests` 库直接打内网接口），
不会有跨域 / 无法访问内网的问题。

## 安装 & 启动

```bash
cd api_test_platform
pip install -r requirements.txt
python app.py
```

启动后打开浏览器访问 `http://127.0.0.1:5050`，会先进入登录页。

## 登录

- 默认账号：`admin`，默认密码：`888888`
- 登录后所有页面和接口才可访问；未登录直接访问 `/` 会跳转到登录页，直接调 `/api/*` 会返回 401
- 右上角「退出登录」可退出当前会话

### 修改密码 / 头像

- 登录后点右上角**头像**，在侧滑面板里可**修改头像**（上传 png/jpg/gif/webp，≤2MB，保存在 `data/avatars/`）
  和**修改密码**，保存后立即生效
- 也可以直接编辑 `data/users.json` 的 `password` 字段（明文保存），改完重启服务生效

> 会话密钥保存在 `data/.secret_key`（首次启动自动生成），重启服务不会导致已登录的会话失效。

## 功能

- **环境管理**：左侧「环境」里维护多套环境（base_url / customer / api_key / auth_seq），
  已经预置了你脚本里的 5.0 和 3.0 环境，点 ✎ 可编辑，✕ 可删除，点右上角 ＋ 新增。
- **接口预设**：左侧「接口预设」维护每个接口的路径和默认请求体模板，已预置了
  `callTaskCreateByVoiceTransferAgent`。以后要测 `getAgentInfo`、`queryTaskInfo` 等接口，
  照着现有的脚本内容点 ＋ 新增一个预设即可，不用再改代码。
- **单环境测试**：选接口 + 选环境，编辑请求体 JSON，点「发送请求」，右侧直接显示
  HTTP 状态码、耗时、完整响应（自动帮你算好 timestamp / digest 签名）。
  请求体写完点「保存」可把当前内容存为接口预设模板（双环境模式下 A / B 各自保存）。
- **双环境对比**：选接口 + 环境 A / 环境 B，一次请求同时打两个环境，左右并排显示结果。
  双环境模式下 request 分 **A / B 两个独立模板**（接口预设里可分别保存，B 留空则跟随 A），
  适合 5.0 / 3.0 环境变量不同的场景；编辑框上方会标注当前对应的环境名。
- **历史记录**：每次测试自动记到浏览器本地（localStorage），点历史条目能一键回填请求体和结果，
  方便回看之前测过的用例。
- **批量执行**：左侧「接口预设」勾选多个接口 → 点「批量执行」，同时请求 5.0 和 3.0 两个环境，
  自动对比响应差异并生成执行结果（执行概览：总接口/通过/失败/存在差异/通过率/总耗时；
  接口列表：状态、两个环境的 HTTP/业务结果、差异数；点「查看详情」看完整 Response 与差异明细）。
  结果判定综合 HTTP 状态码 + 业务返回码（如 HTTP 200 但 error=8 判为失败）+ 双环境差异。

## 数据存放

环境和接口预设会保存在 `data/environments.json` 和 `data/interfaces.json`
（首次保存时自动创建），账号在 `data/users.json`，换电脑或者备份的话直接拷走 `data` 目录即可。

## 后续扩展建议

如果你想把 `getAgentInfo.py`、`queryTaskInfo.py` 这些脚本也接进来，
只需要在网页上点「接口预设」的 ＋，填入对应的接口路径和请求体模板即可 ——
认证签名逻辑（`generate_sign`）是通用的，不需要改后端代码。
